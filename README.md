# 淘宝用户购物行为分析

# 项目简介
本项目基于阿里天池公开淘宝用户购物行为数据集，完成数据清洗、指标计算与可视化分析，挖掘用户访问活跃度、转化链路、活跃时段以及用户留存特征，为电商平台运营策略优化提供参考依据。

# 数据来源
数据源：原始数据集来源于阿里天池官方网站提供的官方数据集《淘宝用户购物行为数据集》
时间范围:2017年11月25日至2017年12月3日之间
数据内容：有行为的约一百万随机用户的所有行为（行为包括点击、购买、加购、喜欢）。数据集的组织形式和MovieLens-20M类似，即数据集的每一行表示一条用户行为，由用户ID、商品ID、商品类目ID、行为类型和时间戳组成，并以制表符分隔。

## 数据集来源
阿里天池公开数据集：淘宝用户行为数据集

# 数据字段说明
|字段|含义|
|----|----|
|user_id|用户ID|
|item_id|商品ID|
|category_id|商品类目ID|
|behavior_type|行为类型：pv(点击浏览)、fav(收藏)、cart(加购)、buy(购买)|
|timestamp|行为发生时间戳|

# 技术栈
- MySQL（DBeaver）：数据清洗、业务指标计算，导出统计结果
- Python 3.9+：Pandas数据读取、Matplotlib可视化绘图、datetime时间处理
- Git + GitHub：项目版本管理与代码托管
- pymysql：MySQL数据库连接与数据读取

# 项目流程
1. 将原始数据集导入MySQL，完成数据清洗，剔除脏数据；
2. 使用SQL统计核心业务指标：总PV、总UV、每日DAU、用户行为转化漏斗、24小时时段用户行为分布、用户活跃日期明细，导出指标结果为CSV；
3. Python读取本地CSV统计结果，计算次日留存指标，绘制4张可视化图表；
4. 结合图表进行业务解读，输出运营建议。

## 核心指标说明
- PV：页面浏览/点击行为总次数
- UV：独立访问用户总数
- DAU：日活跃用户数量
- 转化漏斗：浏览→收藏→加购→购买，衡量用户逐层转化流失情况
- 次日留存：当日活跃用户，在第二天再次访问平台的用户占比

## 业务分析结论
1. **日活跃用户DAU**
日常用户活跃度保持平稳，在双十二预热阶段DAU出现明显暴涨，大促活动可以有效拉动平台用户访问量。
2. **用户转化漏斗**
从浏览到最终购买，用户逐层流失显著。大部分用户停留在浏览环节，从收藏、加购到下单存在较大的转化提升空间，可以针对加购未下单的用户推送优惠，做召回运营。
3. **24小时用户行为分布**
用户活跃度在白天逐步上升，晚间达到访问峰值。平台可以将运营活动、商品上新、优惠投放安排在晚间高峰时段，最大化曝光效果。
4. **次日留存分析**
大促预热带来大量新增用户，但新增用户的次日留存偏低。平台需要思考优化新用户体验，提升新用户粘性。
