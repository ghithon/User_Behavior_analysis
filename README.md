# 淘宝用户购物行为分析

# 项目简介
本项目基于淘宝用户购物行为数据，完成数据清洗、特征工程、模型训练与评估，探究用户购物行为模式。

# 数据来源
数据源：原始数据集来源于阿里天池官方网站提供的官方数据集《淘宝用户购物行为数据集》
时间范围:2017年11月25日至2017年12月3日之间
数据内容：有行为的约一百万随机用户的所有行为（行为包括点击、购买、加购、喜欢）。数据集的组织形式和MovieLens-20M类似，即数据集的每一行表示一条用户行为，由用户ID、商品ID、商品类目ID、行为类型和时间戳组成，并以制表符分隔。

# 文件说明
|字段|含义|
|----|----|
|user_id|用户ID|
|item_id|商品ID|
|category_id|商品类目ID|
|behavior_type|行为类型：pv(点击浏览)、fav(收藏)、cart(加购)、buy(购买)|
|timestamp|行为发生时间戳|

# 技术栈
- Python 3.9+
- pandas：数据读取、去重、时间转换、聚合统计
- matplotlib：业务可视化，漏斗图、时间趋势图
- datetime：时间戳解析，提取日期、小时维度
